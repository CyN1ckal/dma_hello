# dma_hello

See `README.md`. Build with `build.bat` or CMake on the build PC. `deploy_to_target.bat DEST` copies a Release build to the FPGA host. From that directory, run `bin\dma_hello.exe --hello` or `bin\dma_hello.exe --ark --beep`.
